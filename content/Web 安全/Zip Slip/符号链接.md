---
通过 `ln` 命令配合 `-s` 参数：

```bash
ln -s <target> <symbolic>
```

这会建立一个符号链接 `<symbolic>` 指向 `<target>`。

例子：

```bash
$ ln -s / x

$ ll x
lrwxrwxrwx 1 zyf zyf 1 11月23日 14:22 x -> /
```

**注意**，符号链接名不能和对应目录的现有文件名冲突。比如，当前目录下已经有一个叫 `x` 的目录了：

```bash
$ ll
drwxrwxr-x 1 zyf zyf    0 11月23日 14:24 x
```

你就不能再在当前目录中创建一个名为 `x` 的符号链接。
