## URL 片段

URL 片段在客户端（比如浏览器）上才有效果，因此在 HTTP 请求中基本上都会剥离 URL 片段。

这也是为什么在 Burp Suite 中的请求报文中基本上看不到 URL 片段。

而在 OAuth 的隐式授权类型中，关键的访问令牌就放在 URL 片段中。根据流程，在

- 重定向响应
- 户代理发起重定向的操作

中都能看到存有访问令牌的 URL 片段，但如果你要在 Burp Suite 中寻找，则只能在重定向响应中找：
