## URL 片段

URL 片段在客户端（比如浏览器）上才有效果，因此在 HTTP 请求中基本上都会剥离 URL 片段。

这也是为什么在 Burp Suite 中的请求报文中基本上看不到 URL 片段。

在 OAuth 的隐式授权类型中，URL 片段中存在大量关键信息。不过好在，隐式授权是通过让用户浏览器重定向到含 URL 片段的端点，也就是说你会看到这么一条响应包含 URL 片段：
