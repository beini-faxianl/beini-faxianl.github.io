## Claude Opus 5.5（High）

**睡眠（Sleep）**和**休眠（Hibernate）**都是让电脑暂停工作、之后能恢复原状的省电方式。两者的区别在于当前的工作状态保存在哪里。

**睡眠**
- **原理**：工作状态（打开的程序、文档等）留在**内存（RAM）**里。CPU、硬盘、屏幕等大部分部件断电或进入低功耗，只给内存保留少量供电，让数据不丢失。
- **唤醒速度**：很快，通常一两秒。
- **耗电**：仍有少量耗电。笔记本放久了会慢慢掉电。
- **风险**：如果完全断电（拔掉电源，或电池耗尽），内存里的数据会丢失，没保存的工作就没了。
- **在 ACPI 标准里**：叫 S3 状态（"挂起到内存"，Suspend to RAM）。

**休眠**
- **原理**：先把内存里的全部内容写进**硬盘**（Windows 存在 `hiberfil.sys` 文件里），然后彻底关机。
- **唤醒速度**：比睡眠慢，要把数据从硬盘读回内存。用 SSD 一般十几秒左右，比正常开机快一些。
- **耗电**：几乎为零，和关机一样。
- **优点**：断电也不怕，下次开机能恢复到休眠前的状态。
- **在 ACPI 标准里**：叫 S4 状态（"挂起到硬盘"，Suspend to Disk）。

**对比**

| | 睡眠 | 休眠 |
|---|---|---|
| 数据存在 | 内存 | 硬盘 |
| 是否耗电 | 少量 | 基本不耗 |
| 恢复速度 | 很快 | 较慢 |
| 断电后 | 数据丢失 | 数据保留 |
| 适合场景 | 短时间离开 | 长时间不用、需要保留工作现场 |

**补充两点**
- **混合睡眠**（Windows 台式机常见）：既把数据留在内存，又在硬盘上备份一份。平时像睡眠一样快速唤醒，意外断电时又能像休眠一样恢复。
- **现代待机**（Modern Standby，S0ix）：很多新款 Windows 笔记本用它代替传统睡眠。机器像手机一样处在低功耗"在线"状态，可以在后台收邮件、更新，但有时会比传统睡眠更耗电。

简单来说：短暂离开就用睡眠，几小时以上不用或担心没电就用休眠。
