## 总体原则

四条原则：

1. 第一性原理（把基础、底层、原理掌握清楚）
2. 深度优先，兼顾广度
3. 实践驱动，产出闭环（多实践，实践完必须有产出，产出要反过来服务下一次实践（具体参考[[笔记应该记录什么？|这篇笔记]]））
4. 持续学习

## 学习方法

| 方法             | 适用      | 描述                                                                              |
| -------------- | ------- | ------------------------------------------------------------------------------- |
| Learn by doing | 输入      | 通过实践来掌握知识或技能，而不是只靠看、听或阅读理论。                                                     |
| 费曼学习法          | 输出      | 把学到的知识用自己的话、尽量简单清晰地讲给别人听（或假装讲给别人听），从而发现自己没真正理解的地方并不断补漏、深化理解。                    |
| 影子学习           | 输入 + 输出 | 新员工像“影子”一样跟在一位有经验的老员工身边，看他怎么工作、怎么思考、怎么解决问题，从而吸收他的经验。（这里不是真的要“面对面”，通过博客、视频也可以做到） |

## 几句想说的话

- 保持谦虚，持续学习
- 对自己的领域保持激情与耐心
- 人脉很重要
- Google 与 AI 是你最好的朋友（当然，对 AI 你得时刻保持怀疑态度，见[[正确使用 AI|这篇文章]]）
- 敢于提问（即便提的问题很愚蠢）、敢于交流（即便表述的内容存在错误）
