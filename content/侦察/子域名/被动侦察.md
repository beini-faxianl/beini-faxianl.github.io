## subfinder

[subfinder](https://github.com/projectdiscovery/subfinder) 通过在线数据源被动搜集目标域名的子域名信息。

无需配置源 API：

```bash
subfinder -d example.com -s crtsh,crtname,waybackarchive,commoncrawl,rapiddns,digitorus,hackertarget,anubis,subdomaincenter -silent -o subs.txt
```

需配置源 API：

```bash
subfinder -d example.com -s crtsh,crtname,waybackarchive,commoncrawl,rapiddns,digitorus,hackertarget,anubis,subdomaincenter,chaos,virustotal,github -silent -o subs.txt
```

配置 API 的文件默认在 `~/.config/subfinder/provider-config.yaml`。

无需过度在意额度，因为额度达到上限之后，会报错（而不是扣费）。

### Chaos

1. 打开 [https://cloud.projectdiscovery.io](https://cloud.projectdiscovery.io) 注册/登录
2. 登录后在账户设置里找到 API Key
3. 复制 Key

### VirusTotal

1. 打开 [https://www.virustotal.com](https://www.virustotal.com) 注册账号
2. 登录后访问 [https://www.virustotal.com/gui/my-apikey](https://www.virustotal.com/gui/my-apikey) 或点击头像 → API Key
3. 复制 API Key

### GitHub

1. 打开 [https://github.com/settings/tokens](https://github.com/settings/tokens)
2. 选择 Fine-grained tokens（推荐）或 Classic token
3. 生成 Token 时权限至少勾选：
4. 复制生成的 Token（只会显示一次）
