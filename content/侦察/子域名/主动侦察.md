## 对 subfinder 的结果进行核实

假设，`subfinder` 的结果存放在 `subs.txt` 文件中：

```bash
cat subs.txt | dnsx -silent | httpx -silent -status-code -title -tech-detect -o live.txt
```

[dnsx](https://github.com/projectdiscovery/dnsx) 在上述用法中，用于查询域名的 A 记录，如果能查询到，则原样输出该域名，如果查不到则什么也不输出。

[httpx](https://github.com/projectdiscovery/httpx) 是现代版的 `curl`，通过直接发起 HTTP 请求来增加域名是否存活的可信度。

**有个坑点**，Unix 系统中，大多会自带 Python 版的 `httpx`，该版本缺少很多的功能，需要下载 Go 版本的 `httpx`：

```bash
go install -v github.com/projectdiscovery/httpx/cmd/httpx@latest
```

下载完成之后，默认会安装在 `~/go/bin/httpx`，你需要设置别名来避免冲突：

```bash
mv ~/go/bin/httpx ~/go/bin/httpx-pd
```
