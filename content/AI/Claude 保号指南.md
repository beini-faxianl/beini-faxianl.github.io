## 误区

### 机房 IP

是否是机房 IP 其实并不是重点，重点在于：

| 重点          | 描述                                                              |
| ----------- | --------------------------------------------------------------- |
| IP 是否稳定     | IP 不能频繁切换                                                       |
| IP 是否是自己独享的 | IP 如果共享，则可能会出现连坐封号、IP 被封等不稳定因素。因此，建议自己搭建 VPS 或者使用一些代理厂商提供的独享套餐。 |

但使用机房 IP 也有一定的风险，之前就出现过“Bot 验证一直没通过”的问题。

### 中文提示词

使用中文提示词完全没有问题，Claude 不会因为语言而封号。

## 指南

### 环境配置

1. 使用稳定、独享的 IP（通过自建 VPS 或者使用一些代理厂商提供的独享套餐）
2. 将电脑的系统时区切换成美国时区（嫌麻烦可以让 Agent 实现）
3. 将电脑的系统语言切换成英文（嫌麻烦可以让 Agent 实现）
4. 使用 Claude Desktop（Claude 网页版对网络环境要求极为苛刻，极易导致封号）
5. 如果之前有被封的情况，需要彻底删除 Claude Desktop、Claude Code 后（这一过程可以让 Agent 实现，删得很干净）再重新下载，并且彻底删除浏览器记录（同样，可以让 Agent 完成），避免与被封账号产生任何关联
6. 账号升级务必使用苹果/谷歌礼品卡（闲鱼可买）进行内购，切勿使用来路不明的信用卡代充
7. 使用代理的时候，开启 TUN 模式，避免一些操作没有走代理

### 使用时的注意事项

- 刚创建的账号不要直接订阅（正常免费账户用个一两天再上订阅）
- 不要触发五小时限额
- 不使用的时候记得彻底关闭应用
- 关闭 Claude Desktop 的开机自启动
