## 损失与损失函数

模型预测值与真实值之间的差异就是**损失**。

模型训练，练的就是将损失最小化。

差异的计算可能会出现正负号，为了防止抵消，我们通常需要消除符号：

- 取绝对值，或者
- 取平方

这就引出了很多的损失计算方法，即**损失函数**。

比如在[[线性回归]]中，有下述几种损失函数：

| 损失类型         | 损失函数                                                     |
| ------------ | -------------------------------------------------------- |
| $L_1$ 损失     | $\sum \lvert \text{实际值} - \text{预测值} \rvert$             |
| 平均绝对误差 (MAE) | $\frac{1}{N} \sum \lvert \text{实际值} - \text{预测值} \rvert$ |
| $L_2$ 损失     | $\sum (\text{实际值} - \text{预测值})^2$                       |
| 均方误差 (MSE)   | $\frac{1}{N} \sum (\text{实际值} - \text{预测值})^2$           |
| 均方根误差 (RMSE) | $\sqrt{\frac{1}{N} \sum (\text{实际值} - \text{预测值})^2}$    |

不同的损失函数，会有不同的侧重点。比如平方操作其实会将差异放大（大的越大，小的越小），这可能使得模型会更加关注那些异常值（或者说离群值），使最终训练得到的模型会更加靠近那些异常值。
