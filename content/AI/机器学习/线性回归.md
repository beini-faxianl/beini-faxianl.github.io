线性回归这个概念源于统计学，其表达式：
$$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \beta_p X_p + \varepsilon$$
其中：

- $Y$ 是因变量（响应变量）
- $X_1, \dots, X_p$ 是自变量（解释变量）
- $\beta_0, \beta_1, \dots, \beta_p$ 是回归系数
- $\varepsilon$ 是随机误差项

$\varepsilon$ 是整个表达式的精髓，因为它的存在，解释变量和响应变量之间就无法只通过一个线性表达式来准确表示他们的关系，这就有点“预测”、“估计”的意味在里面了。

想象一条直线，其描述的点不都在直线上，但是都在其附近：

![[Pasted image 20261118070403.png]]

那么这条直线其实就能大致描述解释变量与响应变量之间的关系。而关系描述得准不准确，这就得看回归系数的质量了（直线能否让所有点都尽可能地“依附”在自己旁边）。

这其实很好地展现了“回归”这一词 → 将真实值回归到这条代表线上。

>[!info]
> 回归这个词源于统计学家高尔顿对人类身高的研究，他发现父母身高很高或很矮时，子女的身高往往会向人类平均身高靠拢，他将这种现象称为“向均值回归”。

关于回归系数的计算，在统计学中会采用最小二乘法（Ordinary Least Squares，简称 OLS），机器学习中的简单场景（数据量和特征数量少）也会应用这个，但是大多数情况还是采用[[梯度下降]]算法。

回到机器学习，在监督学习中，会有一个训练集。比如通过汽车的重量预测其燃油效率的场景，有以下数据集：

| 千磅（特征） | 每加仑行驶英里数（标签） |
| ------ | ------------ |
| 3.5    | 18           |
| 3.69   | 15           |
| 3.44   | 18           |
| 3.43   | 16           |
| 4.34   | 15           |
| 4.42   | 14           |
| 2.37   | 24           |

将上述信息展现在一个二元坐标系中：

![[Pasted image 20261118030309.png]]

此时，我们定义一个线性回归模型：
$$y^{'}=b+w_1x_1$$
其中：

- $y^{'}$ 是预测标签，即输出
- $x_1$ 是特征，即输入
- $b$ 是模型的偏置
- $w_1$ 是特征 $x_1$ 的权重

训练期间，模型就会通过某种方法（OLS 或者梯度下降算法）来找到那条最佳直线，即计算出最佳权重和偏置：

![[Pasted image 20261118031005.png]]
