## 关于这个博客网站

使用 Claude Opus 5.5（Extra）Vibe 得这个网站，无论是电脑还是移动端都能有不错的阅读体验。

文章页面支持：

| 功能    | 描述                                                                                                                                                       |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 阅读设置  | 字号、行距、字间距、段间距、页面宽度、文字亮度、字体（宋体 / 黑体 / 楷体）、两端对齐、首行缩进。均支持实时生效并记住。                                                                                           |
| 快捷键支持 | 按 `?` 查看全部快捷键。                                                                                                                                           |
| 主题    | 浅色 / 深色 / 跟随系统                                                                                                                                           |
| 批注功能  | 阅读页右下角 ✎，或按 `A`，支持：笔、荧光笔、激光笔、橡皮擦；6 种颜色、3 种粗细；按住 `Shift` 画直线；撤销 / 重做（`Ctrl+Z` / `Ctrl+Shift+Z`）；**一键清除全部痕迹**（可撤销）；支持数位笔压感；触屏上单指书写、双指滚动；批注保存在本机浏览器中，按文章区分。 |
| Zen   | 支持专注阅读。                                                                                                                                                  |
| ……    | ……                                                                                                                                                       |

本项目部署在 Github Page 上，因此是开源的，可在我的 Github [仓库]()中找到。
